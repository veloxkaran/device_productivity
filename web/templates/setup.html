Welcome to My Monitor

Here's exactly what this app does and what data it collects.

  • 📸
    Screenshot capture
    Takes a screenshot every 3 minutes and saves it locally. All data stays on your machine — nothing is sent to external servers.
  • ⏱
    Activity monitoring
    Records whether you are active or idle every 30 seconds using system idle-time APIs. No keystrokes or mouse input is logged.
  • 🔒
    Local-only storage
    Everything is stored in an SQLite database at data/monitor.db on your local disk. Access is protected by a username and password.
  • 🌐
    Web dashboard
    Browse screenshots and activity logs through a local web interface at http://localhost:8080.
Privacy note: My Monitor is a local tool for personal productivity tracking. No data ever leaves your computer.
Permissions & Requirements
{{if eq .Platform "darwin"}}

My Monitor needs Screen Recording permission to capture screenshots. Without it, screencapture silently produces a blank image.

{{else if eq .Platform "linux"}}

My Monitor uses scrot for screenshots and xprintidle for idle detection. Install them with: sudo apt install scrot xprintidle

{{else}}

On Windows, My Monitor uses built-in Win32 APIs for screenshots and idle detection. No special permissions are required.

{{end}}

How to grant Screen Recording:
  1. Click "Open Screen Recording Settings" below.
  2. In the list, find Terminal (or your shell app) and enable it.
  3. After enabling, quit and reopen Terminal, then click Recheck.
  4. Click "Recheck" once you've granted access.

Auto-start on Login

{{if eq .Platform "darwin"}} Install a macOS LaunchAgent so My Monitor starts automatically every time you log in — even after a reboot. {{else if eq .Platform "linux"}} Install a systemd user service so My Monitor starts automatically every time you log in. {{else}} Add a Windows startup entry (registry) so My Monitor starts automatically every time you log in. {{end}}

{{if eq .Platform "darwin"}} LaunchAgent {{else if eq .Platform "linux"}} Systemd User Service {{else}} Startup Registry Entry {{end}} Checking…

{{if eq .Platform "darwin"}} What it does: Writes a .plist file to ~/Library/LaunchAgents/ and registers it with launchctl. {{else if eq .Platform "linux"}} What it does: Writes a .service file to ~/.config/systemd/user/ and enables it with systemctl --user. {{else}} What it does: Adds an entry to HKCU\Software\Microsoft\Windows\CurrentVersion\Run so the app launches at login. {{end}} My Monitor restarts automatically if it crashes.
